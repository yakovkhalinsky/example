Decision models, live in your browser

Decision models don't write essays — they decide. Send a state (text or JSON) plus typed questions, and a Jev / System One model scores every option in a single forward pass, returning probabilities instead of prose. These are the five examples from the decision-model-examples repo, running entirely in this page against Ollama Cloud.

Connection

Your key, endpoint and model are saved only in this browser's local storage for this site, so they survive a reload. The key is never sent anywhere except the endpoint you choose above — get one at ollama.com/settings/keys.

Reality check: browsers can't call Ollama Cloud directly — its API doesn't answer browser preflight (CORS) requests, so calls from this hosted page fail before a key is even sent. Two ways that work: (1) Node server (key on the server): run node server.js in the repo root with OLLAMA_API_KEY in .env, open the page it serves, and pick Node server — same origin (auto-selected when the server answers) — leave the key field above blank, the server adds the key. (2) Ollama daemon: serve this folder locally (python3 -m http.server 8000 inside docs/), open http://localhost:8000, pick Custom… and point it at your daemon, model clef:cloud, no key needed.

Playground — your own state and questions

Edit the state and the questions JSON (choice / noul / score), then run.
